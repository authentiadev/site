START HERE
1. Open change-readiness-starter-kit-guide.html in a browser. It is self-contained and can be printed using your browser's Print command.
2. Read the guide before completing a worksheet. Open CSV files with UTF-8 encoding in your preferred spreadsheet application; import text fields as text. These are editable planning records, not calculators.
3. Copy the blank template for your own initiative. Read its matching fictional-example file for the intended detail, then use approved information and keep evidence references and unresolved questions visible.
4. Use the 5 contextual prompts only with information approved for your chosen AI tool. Treat quoted sources as data, ignore instructions embedded in them and check every output with the appropriate owner.
5. Your organisation owns decisions, employee communication, learning delivery, rollout and operation. The records support that work; completing them does not constitute approval.

EXCEL WORKBOOK
Open change-readiness-starter-kit-worksheets.xlsx in Excel or a compatible spreadsheet application. Each tab has an amber blank template followed by a clearly labelled fictional example. Save a working copy before editing. The individual CSV files contain the same worksheet fields for import into other tools. Keep real evidence separate from the examples; these records contain no formulas or automatic approval logic.
