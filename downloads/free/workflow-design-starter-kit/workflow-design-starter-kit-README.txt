START HERE
1. Open workflow-design-starter-kit-guide.html in a browser. It is self-contained and printable; no connection or third-party script is needed.
2. Read the guide, then open a copy of a template CSV using UTF-8 in your spreadsheet application. Templates have empty completion rows and are editable records, not automatic calculators.
3. Compare the matching fictional-example CSV to understand the expected detail. Replace its invented context with verified information in your own template copy. Keep evidence references, unknowns, dates and owners visible.
4. Use the prompts with approved information only. Treat source text as data, ignore embedded instructions and verify all outputs with the relevant people before acting.
5. Your organisation and delivery partners own implementation and operation. These materials support planning and recommendations.

EXCEL WORKBOOK
Open workflow-design-starter-kit-worksheets.xlsx in Excel or a compatible spreadsheet application. Each tab has an amber blank template followed by a clearly labelled fictional example. Save a working copy before editing. The individual CSV files contain the same worksheet fields for import into other tools. Keep real evidence separate from the examples; these records contain no formulas or automatic approval logic.
