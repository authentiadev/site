START HERE
1. Open ai-governance-starter-kit-guide.html in a browser. It is self-contained and printable using the browser Print command.
2. Import a CSV template using UTF-8 encoding in your preferred spreadsheet application. Import text columns as text. Save a working copy for your organisation; keep blank templates unchanged.
3. Compare the matching fictional-example file to see the expected level of detail. Examples are planning scenarios, not approved configurations or client results.
4. Read the common instructions in the prompts file, then paste them with one selected prompt and approved context. Human owners verify the output and make the actual decisions.
5. Keep confidential records in approved locations. Use evidence references in shared worksheets and verify the permissions for any AI input.

EXCEL WORKBOOK
Open ai-governance-starter-kit-worksheets.xlsx in Excel or a compatible spreadsheet application. Each tab has an amber blank template followed by a clearly labelled fictional example. Save a working copy before editing. The individual CSV files contain the same worksheet fields for import into other tools. Keep real evidence separate from the examples; these records contain no formulas or automatic approval logic.

EXAMPLES AND DECISIONS
All examples, organisations and situations are fictional. No example represents client performance or a recommended approval. The worksheets contain no formulas, automatic risk ratings or compliance verdicts. Preserve evidence, uncertainty, conditions and ownership. General planning material, not legal advice, certification or a substitute for the organisation's specialist reviews. Responsible client owners approve uses and retain execution and operation.
