START HERE
1. Open ai-opportunity-scorecard-guide.html in a browser. The guide is self-contained and can be printed using your browser's Print command.
2. Open a CSV template in your preferred spreadsheet application using UTF-8 encoding. Templates are editable records, not automatic calculators. Import text columns as text. Numeric example inputs are illustrative only.
3. Read the matching fictional-example CSV to understand the expected detail. Create a copy of the template for your organization, replace the example context and retain evidence references.
4. Use the contextual prompts only with approved information and review the output with the appropriate owners.
